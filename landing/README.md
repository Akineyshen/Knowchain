# 🚀 CryptoSwap Landing Page

Modern cryptocurrency landing page built with Vue 3, TypeScript, and SCSS.

## ✨ Features

- 🎨 Modern, glassmorphism design
- 📱 Fully responsive (mobile, tablet, desktop)
- ⚡ Lightning-fast performance with Vite
- 🎭 Smooth animations and transitions
- 🧩 Component-based architecture
- 💎 SCSS modules for styling
- 🔥 TypeScript for type safety

## 🏗️ Project Structure

```
src/
├── components/
│   ├── Header/
│   │   ├── Header.vue
│   │   └── Header.module.scss
│   ├── Hero/
│   ├── WhyChoose/
│   ├── Features/
│   ├── CryptoList/
│   ├── Security/
│   └── Footer/
├── styles/
│   ├── variables.scss
│   └── global.scss
└── App.vue
```

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

- **Header** - Sticky navigation with mobile menu
- **Hero** - Eye-catching hero section with phone mockup

- **Features** - Detailed feature sections with visuals
- **CryptoList** - Animated crypto asset carousel

- **Footer** - Newsletter signup and footer links
